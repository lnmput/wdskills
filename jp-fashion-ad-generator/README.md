# JP Fashion Ad Generator

面向日本市场女装商品的社交媒体广告生成Skill。它可以根据商品图片和已确认资料，制作日文营销文案、Instagram/Facebook画面方案，以及4:5 Feed和9:16 Story/Reels图片。

## 如何调用

最稳定的方式是显式调用：

```text
使用 $jp-fashion-ad-generator，为这件女装制作日文Instagram广告和配图。
```

也可以直接描述日本女装、日文营销和社交媒体广告需求，Codex会在匹配时自动调用。仅说“帮我出图”通常不足以触发本Skill。

## 使用流程

1. 上传商品图片，并提供已确认的商品资料和广告目标。
2. 选择图片“带字”或“不带字”；未说明时Skill会先询问。
3. 检查营销方案，包括图片文字、独立Caption、Hashtag和构图。
4. 回复“确认”或提出修改意见。
5. 方案确认后才生成正式图片，避免理解错误和重复消耗。

## 最少需要提供什么

只需一张清晰商品图也能开始。推荐至少说明：

```text
使用 $jp-fashion-ad-generator。
商品：米白色通勤连衣裙，具体设计以附件为准。
目标：日本Instagram，面向需要通勤穿搭灵感的人群。
场景：春季工作日，办公室附近咖啡店。
图片：带日文文字，制作4:5和9:16版本。
```

## 怎样描述，图片质量会更好

### 1. 提供清晰、多角度参考图

最好提供：

- 正面全身图；
- 背面或侧面图；
- 领口、袖口、纽扣、印花等细节图；
- 接近真实颜色、没有重度滤镜的原图。

如果只有一张图，应明确写：`看不清的设计不要自行补充，商品细节以参考图为准。`

### 2. 把已确认事实和视觉偏好分开

商品事实决定广告能说什么，视觉偏好决定图片长什么样。例如：

```text
已确认商品信息：聚酯纤维，后背拉链，有内衬，春秋款。
视觉偏好：安静、克制、日系杂志感，自然日光，不要强促销风格。
```

不要仅凭图片要求“抗皱、保暖、显瘦、久坐舒适”等功能卖点；这些信息需要商品资料支持。

### 3. 描述真实场景，而不是只写风格词

比起“高级、好看、有氛围”，下面这种描述更容易得到稳定结果：

```text
东京丸之内工作日上午8:30，现代办公楼入口附近。
模特自然走向镜头，一手拿简洁通勤包，神情从容。
柔和晨光，背景有人但轻微虚化，重点清楚展示连衣裙完整轮廓。
```

场景描述建议包含：地点、时间、动作、情绪、光线和背景复杂度。

默认会以服装为参考，重新构建穿戴场景，而不是沿用原照片换背景或扩图。营销方案会先说明保留哪些商品细节，以及新场景、动作和镜头与原图的区别，等你确认后生成。例如：

```text
只参考这张图里的衣服，不沿用原图的镜自拍姿势、手机和室内背景。
重新构建周末逛街的穿戴场景：成年模特走出街边花店，一手提花束，
正面全身抓拍，自然日光，衣服的颜色、剪裁和设计细节保持一致。
先给我确认营销方案，不要直接出图。
```

需要同一模特时补充“保留原模特身份，但重新设计动作和镜头”。如果只想换背景，明确写“保留原照片人物和姿势，只换背景”。只有正面图时，不要要求 AI 凭空还原背面设计；补充背面图更可靠。

### 4. 明确商品不能被改变的细节

商品广告最重要的是服装一致性。可以写：

```text
必须保持原始米白色、圆领、七分袖、腰线位置、裙长和后背拉链；
不要增加腰带、口袋、开衩、Logo或装饰；不要改变面料纹理。
```

如果某个细节必须准确，最好同时上传对应局部图。

### 5. 明确人物和动作

建议说明：

- 明确成年模特；
- 全身、半身或商品静物；
- 站立、步行、坐姿或回眸；
- 表情和视线方向；
- 手中是否持有包、手机或咖啡杯。

动作不要过多。单张广告图通常选择一个主要动作，服装更容易保持完整。

### 6. 带字时控制文字数量

图片上的日文越少，越容易保持可读性。建议使用：

- 一条短标题；
- 一条短副标题；
- 一个简短CTA。

不要把完整Caption塞进图片。Skill会从构图库选择合适版式，并尽量避免重复最近使用的构图。

选择带字时，只交付带字成品：常规双尺寸为4:5和9:16各一张，不额外生成或展示无字版本。确需分层排字的中间素材不作为独立交付；只有明确要求同时提供无字版时才增加。

使用CTA按钮时，文字必须在按钮内部水平、垂直居中，按实际字形检查左右及上下留白，不用空格凑位置。两个尺寸分别检查；图像模型的居中指令不能代替成图复核。发布前也应检查日文错字、乱码和缺字。

### 7. 给出明确的排除项

只写最重要的限制，例如：

```text
不要改变商品颜色；不要新增服装设计；不要夸张广角；
不要塑料感皮肤；不要杂乱背景；不要红黄大促销标签。
```

排除项过多或互相冲突反而会降低稳定性。

### 8. 明确画布尺寸和数量

只要一张Feed图时可以写：

```text
只制作1张带字成品，画布宽1080、高1350，比例严格为4:5。
不要另做9:16。全身人物、日文和细节窗口都放在这个画布内部，
不要加长画布，也不要继承参考图的比例。
如果工具无法直接保证此尺寸，请在营销方案阶段说明；不要自动二次生成。
```

Skill会逐张锁定尺寸并读取实际像素检查；“约4:5”不算精确达标。但只有Prompt、没有独立尺寸参数的图像工具，仍可能不严格遵循指定尺寸，不能保证首次成功。

## 注意事项

- Skill不会仅凭图片确认材质、性能、库存、销量、排名和再入荷信息。
- 未确认是否带字时，流程会暂停询问，不会替用户默认选择。
- 未确认完整营销方案时，不会生成正式图片。
- 参考图看不到的服装细节可能无法精确复原，应补充对应图片。
- 4:5和9:16会分别重新组织画面，不是简单裁切。
- 商业发布前应检查商品信息、日文、Logo、人物和第三方素材授权。
