# 日本女装社交媒体广告生成器

把商品信息转化为“具体受众在具体场景中的穿搭解决方案”，交付自然的日文文案和可直接用于图像模型的 Prompt。核心内容主线为：**身份/场景 + 具体烦恼 + 有依据的解决方案 + 商品细节 + 收藏或互动理由**。

## 必须遵守的事实边界

先把输入信息分成三类，后续文案和 Prompt 只能使用有依据的内容：

- **图片可观察事实**：品类、颜色、可见纹理、轮廓、领型、袖型、长度、纽扣、印花和其他清晰可见的设计。
- **保守判断**：风格、可能的季节感、搭配方向和适合场景。使用建议性措辞，不写成已验证性能。
- **必须由商品资料或用户确认的事实**：具体材质、抗皱、防汗、保暖、弹力、显瘦、舒适、久坐体验、耐用性、库存、销量、排名、再入荷、价格和功能性效果。

不得仅凭图片推断模特的年龄、职业、身体属性或商品功能。不要把“看起来像”改写成确定事实。资料不足时，仍可基于可观察事实完成文案；避免相关卖点，或简短标注需要用户补充的信息。

## 工作流程

### 1. 提取商品与品牌信息

记录可观察的商品细节和用户明确提供的商品资料。用户只有文字描述时直接使用文字，不强制要求上传图片。

如果品牌明显不是常规通勤风格，例如年轻休闲、高奢、甜酷或户外，不要强行套用通勤公式。已有信息足够时自行调整；品牌定位会实质改变结果且无法判断时再询问。

### 2. 选择 2–3 个内容角度

根据商品和受众选择 2–3 个真正不同的角度，用于标题变体：

| 类型 | 核心手法 | 适用条件 |
|---|---|---|
| 痛点型 | 从具体烦恼切入 | 解决方案有资料支持 |
| 身份型 | 面向明确职业或生活状态 | 用户或品牌给出目标受众 |
| 场景型 | 从具体生活场景切入 | 通勤、会议、出差、聚餐等 |
| 体型友好型 | 强调穿着选择和版型包容度 | 有可见版型或尺码资料支持 |
| 职场型 | 强调得体和场合适配 | 商务或通勤单品 |
| 搭配型 | 一衣多穿或搭配变化 | 基础款、可叠穿单品 |
| 焕新型 | 强调当季搭配更新 | 避免贬低用户已有衣物 |
| 情绪型 | 强调穿着后的积极感受 | 有设计感或风格鲜明的单品 |
| 清单型 | 多件商品合集 | 用户提供多件商品，不虚构数量或排名 |
| 商品型 | 直接介绍具体卖点 | 卖点经过用户资料确认 |

需要标题灵感时读取 `references/headline_examples.md`。参考语感和结构，不逐字照抄，也不要声称复制某个账号的表达。

### 3. 生成日文文案

提供 2–3 个不同角度的标题和 2–3 个 CTA；Caption 和 Hashtag 各一版。日语应自然、具体，避免反复使用「女子」「OL」或「素敵な一着」「あなたにぴったり」等陈旧、空泛表达。

```text
【タイトル案】
① （标题，并标注公式）
② （不同角度的标题）
③ （可选的第三个角度）

【画像用見出し（短縮版）】
（对应首选标题，15个日文字符左右；不是为了让图像模型更准确，而是方便后续排版）

【サブタイトル】
（与当前商品和场景对应，不使用固定句式）

【Caption】
（3–6行：场景/烦恼 → 有依据的解决方案 → 可见或已确认的商品细节 → 收藏/互动引导）

【Hashtag】
（10–15个，按 references/hashtag_library.md 的规则组合）

【CTA案】
① （保存型）
② （互动型）
③ （查看商品型，可选）
```

### 4. 必须确认图片是否带文字

图上是否叠加日文营销文字必须由用户决定。

- 用户在当前或此前对话中已明确说明：直接按其选择继续。
- 用户未说明：**必须先询问并暂停，不得默认生成无文字版，也不得同时替用户生成两版。**
- 推荐问法：`图片上需要直接带日文文案吗？请选择“带字”或“不带字”；确认后我会先提交营销方案给你审核，通过后再生成正式图片。`

这一步是强制确认点。不要用“默认不带字”暗示已经替用户作出选择。

### 5. 必须确认营销方案

用户明确选择带字或不带字后，先提交一份精简的营销方案预览。**用户明确认可之前，不得生成双尺寸详细英文 Prompt，不得调用图像工具，也不得生成正式图片。**

如果用户选择带字，在提交预览前读取 `references/layout_composition_guide.md`，完成候选比较并选定构图；构图必须作为营销方案的一部分一起审核，不能等用户确认文案后再临时更换。

预览必须让用户一次检查完整营销信息：

```text
【营销角度】
目标受众 / 使用场景 / 核心诉求

【图片方案】
生成方式：默认全新穿戴场景；只有用户明确要求时才做原图编辑
新场景的地点/活动、模特动作及环境互动、镜头与光线、商品呈现重点
参考图保留什么、改变什么；是否需要保留原模特身份
交付数量、每张宽×高和宽高比；只做用户要求的尺寸

【图片上的文字】
带字：逐字列出标题、副标题和 CTA
不带字：明确写“图片不带文字”

【单独发布文案】
Caption 全文

【Hashtag】
最终准备使用的标签

【构图参考】（仅带字时）
编号、名称、选择理由和来源链接

【待确认】
请确认以上营销方向、图片文字和单独发布文案是否合适；如需修改，请直接指出。确认后我再生成正式图片。
```

为节省 token，这一阶段只提供足以做决策的中文说明和最终日文文案，不提前展开详细摄影参数、负面 Prompt 或两个尺寸的完整英文 Prompt。标题和 CTA 的备选方案可以简短列出，但必须明确标记推荐使用的最终版本。

- 用户回复“确认”“可以”“按这个生成”或同等明确许可后，才进入下一步。
- 用户要求修改时，只更新受影响的营销文案、图片文字或构图，并再次提交确认；不得一边修改一边直接出图。
- 如果用户此前已经逐字提供并明确批准了本次要使用的完整图片文字和发布文案，该批准可以视为本确认点已完成；仅提供素材或初步想法不算批准。

### 6. 生成出图 Prompt 或正式图片

上述两个确认点都完成后，按确认的数量和尺寸制作。用户只要求4:5时仅制作一张4:5，不追加9:16；只有未指定尺寸时才在营销方案中提出以下双尺寸供确认。如果用户要求直接出图，可把详细Prompt用作内部生成指令，不必额外输出冗长文本：

- `Feed — 1080×1350, portrait 4:5`：适用于 Instagram Feed，并可作为 Facebook Feed 广告素材的纵向版本。
- `Story/Reels — 1080×1920, portrait 9:16`：适用于 Instagram/Facebook Stories 和 Reels；为平台界面保留清晰安全区。

#### 生成前锁定画布（带字、不带字均适用）

- 每张图片单独确定一个目标宽高与比例。每次图像生成调用的Prompt只包含当前图片的尺寸，不同时写4:5和9:16，不仅写含糊的“portrait”。
- 在Prompt开头明确最终外框，例如4:5：`Create exactly one finished ad image. Final outer canvas: 1080 px wide × 1350 px high, exact width:height ratio 4:5. Compose directly inside this canvas; do not create a taller poster for later cropping. No extra outer margins or presentation board.` 9:16使用1080×1920，替换比例而非叠加描述。
- 全身人物、日文标题、CTA和细节窗口都在已定画布内部排布；内容放不下时调整元素占比和留白，不通过向下加长画布容纳内容。参考商品图及构图库图片仅提供内容或布局关系，不继承其外框比例。
- 工具若提供尺寸或比例参数，使用其真实支持的参数与Prompt保持一致；不虚构参数。只有Prompt输入的工具无法保证精确像素尺寸。如果工具已知不支持目标尺寸，或用户明确要求首次精确输出且工具无法保证，在营销方案确认阶段说明限制，不能先生成再临时提出二次调整。

#### 生成后尺寸验收

- 读取实际文件像素宽高，不根据聊天界面缩略图判断。4:5必须满足`宽×5 = 高×4`；9:16必须满足`宽×16 = 高×9`。如果确认了1080×1350等精确像素，还必须逐项核对宽高。1122×1402不是精确4:5，不能以“约4:5”宣称达标。
- 禁止把“先生成长图，再调用图像模型修成目标比例”设为默认流程。仅因比例不符需要额外模型调用时，先报告实际尺寸和限制，征得用户同意后再执行，不无限重试。
- 如用户已授权裁切或画布处理，使用符合当前工具约束的方法，并确保不拉伸商品、不裁掉人物、日文或CTA。未经授权不以拉伸、添加大块空白或改变构图掩盖比例错误。
- 修正版如获准制作，最终只交付符合要求的版本，不把原始偏长图和修正版并列当成两张成品；工具若自动展示中间结果，不承诺可以隐藏它。

#### 参考图只锁定商品，默认重新构建穿戴场景

- 上传商品图或模特图不等于要求编辑原照片。默认把它作为服装身份参考，为已确认的营销场景重新拍摄式生成；不能仅扩展背景、替换背景或把原人物抠入新环境就当作完成新场景。
- 在营销方案中先确定具体地点、正在进行的活动、人物动作与环境互动、镜头和光线，并简述与原图的区别。不能只写“咖啡店背景”或“通勤氛围”；例如“成年模特从办公楼入口走出，手持通勤包，正面全身镜头，晨光与地面投影一致”。确认后按该方案生成，不临时改场景。
- 将商品参考图实际传给支持参考图的生成工具，并明确其用途是服装设计，不是固定原照片的构图、姿势、背景或光线。默认重新安排人物动作和摄影构图，让人物真实参与场景；不要保留原图镜自拍姿势、手机遮脸或棚拍站姿，除非它们正是已确认方案所需。
- 只有用户明确要求同一模特时才锁定人物身份；保持身份不等于保持姿势。否则在方案中提出适合的明确成年模特，不从原图推断年龄、职业。用户要求保留原图、只换背景或扩图时按其明确范围编辑，不能擅自重构。
- 新动作可自然改变褶皱、垂坠、透视和光影，但不能改变服装剪裁或设计。只有正面参考时优先设计能核对的正面或轻微侧向视角；需要展示无法确认的背面等关键细节时索取补充图，不为追求新场景编造设计。
- 新场景Prompt必须包含以下意图并填入已确认场景细节：`Create a fresh lifestyle fashion photograph of an adult model wearing the referenced garment in the approved setting and activity. Use the product reference only to preserve garment identity, not as a base photograph to extend. Rebuild the pose, camera composition, lighting and interaction with the environment coherently. Do not merely outpaint, swap the background, or paste the original model into a new setting.` 用户明确要求保留模特身份时，另行注明人物身份参考；原图编辑任务不套用此段。

每个Prompt都必须包含以下商品一致性要求：

- 把用户提供的商品图作为服装身份参考，不把参考图仅当作氛围图。
- 保持原始颜色、轮廓、领口、袖型、长度、纽扣、印花、缝线和可见配件。
- 不添加或删除口袋、腰带、开衩、装饰、Logo 等设计。
- 参考图中不可见或不清楚的细节不要自行补成显眼设计。
- 默认按已确认方案重新构建场景、姿势和摄影构图，商品本身的视觉身份不得变化；不把服装一致性误解为原照片像素、姿势或褶皱位置不变。

视觉调性应服务于真实商品颜色和品牌定位。日系杂志式留白可以作为常规通勤内容的起点，但不得为了米白灰粉的统一色调改变商品本色，也不要固定排斥品牌本身使用的鲜艳颜色。

#### 用户选择“不带字”

Prompt 明确要求 `no text, no typography, no captions, no logos added to the image`。9:16 版本仍应留出上下安全区，方便用户后期排版。

#### 用户选择“带字”

只生成并交付用户确认的带字成品，不额外生成一套无字版本。常规双尺寸任务最终只交付2张图片：4:5带字成品和9:16带字成品；用户指定其他数量或尺寸时以用户要求为准。交付内容包括：

1. 使用营销方案中已经确认的构图方案；
2. 每个尺寸对应的带字成品，或用户只要Prompt时的带字成品Prompt；
3. 已确认的日文原文和必要的排版说明。

优先直接制作包含已确认日文的最终广告图。确需分层排字时，无字底图只作为合成所需的内部中间素材：不得另开一轮生成额外的无字备选，不得作为独立成品展示、附下载链接或加入预览画廊。只有用户明确要求同时提供无字版时，才增加无字版交付。若工具会自动展示底图，不采用会暴露额外无字图片的工作流；无法完成带字成品时说明限制，不用无字图冒充完成。

#### CTA按钮居中要求

只在已确认方案包含按钮时使用按钮。按钮内文案必须水平、垂直双向居中，左右留白相等、上下留白相等；不要把整张广告的左对齐规则套用到按钮文字。

- 以最终字体渲染后的文字可见边界为准，将文字边界中心与按钮内框中心重合；不能只依靠文本框居中或字体基线估算。
- 使用排版工具时，加载最终字体后测量实际字形边界并对齐；在最终导出的4:5和9:16图片中分别检查。栅格取整允许最多1个输出像素的边距差。
- 日文优先单行显示。文字放不下时调整按钮宽高或字号，不用空格、全角空格或换行凑位置，不裁切文字。
- 不擅自添加图标；若用户要求图标，采用对称占位等布局保持文字本身居中，不能只居中“图标+文字”整体而让文字偏移。
- 直接图像生成的Prompt必须明确写入：`Center the CTA label precisely inside the button, both horizontally and vertically, with equal left/right and top/bottom visible padding. Do not left-align the label.` Prompt不能保证像素精度，必须查看成图；发现偏移优先局部修正按钮，不重新生成整个场景，也不修改已确认文案。

构图参考来自 [nevertoday/350-layout-compositions](https://github.com/nevertoday/350-layout-compositions)。选择时必须结合商品主体、文案长度、信息层级和版位比例，不能固定套用同一种版式。查看得到对话历史时，避开最近3次已使用的构图编号；看不到历史时，先形成至少3个合理候选，再选择最适合当前内容的一个。4:5 和 9:16 使用同一构图逻辑的响应式变体，不得只是机械裁切。

正式生成时不得擅自更换已经确认的构图、图片文字或发布文案；如果技术限制迫使方案变化，先说明变化并重新取得确认。

交付中增加 `【构图参考】编号 + 名称 + 选择理由 + 来源链接`。只借鉴空间关系、阅读顺序和网格逻辑，不复制仓库参考图中的人物、品牌、Logo、文字或具体美术素材。如果对参考图进行了可识别的改编，按 CC BY 4.0 标注来源和改编说明；用于商业广告时仍需确认参考图所含第三方素材权利。

带字Prompt必须逐字引用已经确认的短标题、副标题和CTA，不得使用固定文案，不额外附送另一套无字Prompt；交付前检查日文乱码、错字和缺字，并提醒用户发布前复核。

如果当前环境有可用图像工具且用户明确要求直接出图，可在完成上述确认后生成图片；否则只交付 Prompt，不要声称已经生成图像。

### 7. 输出前自检

- 广告中的材质、性能、销量、库存等陈述是否有明确依据。
- 商品颜色和设计细节是否在 Prompt 中被锁定。
- 新场景任务是否对照参考图检查了人物活动、姿势、摄影构图及环境光影，确实形成已确认的穿戴场景而不只是换背景或扩图；仅有Prompt时不能宣称成图检查通过。若成图仍照搬原图，说明未达标，需额外生成时先征得用户同意，不擅自反复消耗额度。
- 2–3 个标题是否来自真正不同的角度。
- 日语是否自然，是否避免不必要的年龄、职业或身体标签。
- Caption 是否具体到当前商品，而不是空泛赞美。
- Hashtag 是否与真实品类、材质、季节和场景匹配；没有为凑数使用不相关标签。
- CTA 是否与当前目标匹配，并在可见对话历史中避免机械重复。
- 用户是否已经明确选择带字或不带字；没有确认就停止在询问处。
- 用户是否已明确认可完整营销方案；没有认可就不得生成详细 Prompt 或正式图片。
- 带字版本是否记录了构图编号和选择理由，且没有重复最近3次构图。
- 4:5 与 9:16 是否保持同一构图逻辑，同时针对比例重新组织而非直接裁切。
- 每次生成是否只指定一个画布；实际像素是否符合已确认比例和尺寸；未达标不得声称尺寸正确或擅自启动二次生成。
- 带字请求是否只生成、交付已确认数量的带字成品，没有额外无字图片、无字Prompt或中间素材预览。
- 若有CTA按钮，是否在两个尺寸的最终成图中分别检查文字水平和垂直居中、四边留白及文字完整性；仅写了居中Prompt不算检查通过。只交付Prompt时说明尚未进行成图验证。

### 8. 整合交付

把日文文案与已确认尺寸对应的成品或Prompt整合交付，不追加用户未要求的尺寸。用户选择带字时，再附必要的排版规格和日文准确性提醒。只有在用户提供多件商品时才建议制作清单型内容，不虚构 TOP8 或排名。
