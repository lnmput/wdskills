# 营销文案构图选择指南

来源：[nevertoday/350-layout-compositions](https://github.com/nevertoday/350-layout-compositions)。项目提供350种布局的机器可读目录和参考图，采用 [CC BY 4.0](https://github.com/nevertoday/350-layout-compositions/blob/main/LICENSE)。本指南只提取适合女装社交广告的空间与阅读逻辑，不复制参考图中的人物、品牌、Logo、文字或具体美术素材。

仅在用户明确选择“带字”时读取和使用本文件。完整目录以仓库的 [`v2/catalog.csv`](https://github.com/nevertoday/350-layout-compositions/blob/main/v2/catalog.csv) 为准。

## 选择步骤

1. 判断主体：单人全身、半身特写、商品静物、多商品或细节组合。
2. 判断文字：短标题、标题加副标题、或三级信息（标题/副标题/CTA）。
3. 判断气质：安静高级、职场端正、轻快亲和、编辑感或动态冲击。
4. 从下表选出至少3个候选，排除会遮挡服装关键细节或安全区不足的方案。
5. 查看得到历史时排除最近3次使用的编号，再选最匹配本次内容的一个。
6. 输出编号、名称、选择理由和来源链接，并把布局关系写进两个尺寸的 Prompt 与排版规格。

不要随机轮换。多样性必须建立在内容适配上，而不是为了不同而牺牲商品识别与文字可读性。

## 响应式改编

同一个编号用于两个比例，但重新安排空间：

- **4:5 Feed**：优先保证商品占画面主要面积；文字区通常占宽度约25%–40%，或位于稳定负空间。
- **9:16 Story/Reels**：保留顶部和底部平台安全区；人物可略下移，标题、CTA 分别放入独立区域。
- 保持相同的阅读顺序、对齐轴和主体/文字关系，不要求元素坐标完全相同。
- 不通过拉伸、压缩或简单裁掉人物来适配比例。

## 防重复规则

- 可见历史中最近3次使用过的编号进入临时排除集。
- 同一批次多张图不得全部使用同一编号；相邻作品至少更换构图家族，例如从负空间类切换到侧栏类或模块类。
- 品牌系列需要统一时，可以保留字体、颜色和间距体系，但轮换主体位置、文字轴线或构图编号。
- 若唯一符合商品安全和文案可读性的方案恰好重复，可以复用，但必须说明原因，并改变主体方向或文字轴线。
