# Korean Fashion Terminology Glossary

This glossary maps common fashion e-commerce terms from Chinese, English, and Japanese to their preferred Korean equivalents. Always use the Korean term listed here — do not invent new translations for terms that already have an entry.

## How to Use
- When translating, look up the source term in its language column → use the 한국어 column
- If a term is missing and likely to recur → add it with all known source language equivalents
- If you disagree with an existing entry → update it and note the reason
- When two options are listed with `/`, the **first is the default**. Use the second only when the parenthetical note or context applies (e.g., "빈티지" for washed/distressed items, "레트로" for classic vintage)
- If no note explains when to use the second option, always use the first
- Empty cells in a source language column mean the term rarely appears in that language's fashion e-commerce; fill in if you encounter it
